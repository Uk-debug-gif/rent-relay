# RentRelay category-first prototype

Open `index.html` in a browser. This is a static frontend prototype with category pages, subcategory filters, sample rental cards, price per day, and demo request/listing dialogs.

## Categories
- Study Materials
- Books & Copies
- Lab Essentials
- Indoor Games
- Outdoor Sports
- Utensils & Kitchen

## Important
All listings and prices are sample data. Login, student verification, database persistence, real bookings, payment/deposit handling, messaging, and admin moderation are not connected yet. Do not use this prototype to collect real payments or sensitive student information.
